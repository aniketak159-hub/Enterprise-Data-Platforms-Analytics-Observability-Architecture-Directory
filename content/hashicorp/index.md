## Core Capabilities

- **Vault** — Dynamic secrets, encryption-as-a-service, PKI, lease/renewal
- **Terraform Enterprise** — Policy-as-code (Sentinel), private registry, drift detection
- **Consul** — Service discovery, mesh (mTLS), intentions, multi-datacenter
- **Boundary** — Identity-based remote access (zero-trust network)
- **Nomad** — Workload orchestration (containers, VMs, batch)
