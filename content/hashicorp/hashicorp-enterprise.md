## 🔧 Core Capabilities

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin: 24px 0;">

### 🔐 Vault — Secrets Management
**Dynamic secrets, encryption-as-a-service, PKI, lease/renewal** — Centralized secret storage, dynamic database credentials, key management, and automated rotation for zero-trust architectures.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🏗️ Terraform Enterprise — IaC Governance
**Policy-as-code (Sentinel), private registry, drift detection** — Infrastructure automation with governance guardrails, module registry, run tasks, and compliance enforcement across multi-cloud environments.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🌐 Consul — Service Mesh
**Service discovery, mesh (mTLS), intentions, multi-datacenter** — Zero-trust service networking with mutual TLS, traffic segmentation via intentions, and multi-datacenter federation for hybrid cloud.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🚪 Boundary — Identity-Based Access
**Identity-based remote access (zero-trust network)** — Secure remote access to infrastructure without VPNs, using identity-aware proxying and session recording for privileged access management.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### ☸️ Nomad — Workload Orchestration
**Workload orchestration (containers, VMs, batch)** — Flexible scheduler supporting containerized, legacy, and batch workloads with multi-region federation and enterprise governance features.

</div>
