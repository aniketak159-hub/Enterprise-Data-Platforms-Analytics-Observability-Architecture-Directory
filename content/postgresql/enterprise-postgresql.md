## Core Capabilities

- **Oracle PL/SQL Compatibility** — Native PL/SQL execution, packages, triggers
- **Patroni HA** — Automated failover, leader election, streaming replication
- **EDB Migration Toolkit** — Automated schema/code translation from Oracle
- **TPA (Trusted Postgres Architect)** — Reference architectures for HA/DR
- **Compliance Ready** — PCI-DSS, SOX, GDPR, RBI, SAMA aligned
