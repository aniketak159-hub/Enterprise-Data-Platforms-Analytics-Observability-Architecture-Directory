**Distributed columnar storage** for real-time analytics — HTAP workloads with predicate pushdown, late materialization, and 10x compression.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🔀 MaxScale Smart Proxy
**Intelligent query routing** — read/write splitting, firewall, binlog router, and schema routing for transparent scale-out.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🔄 Galera Cluster
**Synchronous multi-master replication** — zero-downtime, automatic failover, geographic distribution with 99.999% availability.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🐘 Oracle Compatibility
**PL/SQL parser, packages, sequences** — Oracle dialect support, data type mapping, and procedural code migration tooling.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### ☁️ SkySQL Managed Cloud
**Fully managed MariaDB** on AWS, Azure, GCP — auto-scaling, backups, monitoring, and enterprise SLAs with data sovereignty.

</div>
