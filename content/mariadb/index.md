# MariaDB Enterprise, SkySQL & RDBMS Modernization

**Category:** Relational Database Platforms | **Platform:** MariaDB Enterprise / SkySQL

---

## Overview

MariaDB Enterprise provides ColumnStore OLAP, MaxScale smart proxy, Galera multi-master HA, Oracle/SQL Server migration tooling, and OEM licensing for mission-critical transactional and analytical workloads.

## Core Capabilities

- **ColumnStore** — Distributed columnar storage for real-time analytics
- **MaxScale** — Intelligent query routing, read/write splitting, firewall
- **Galera Cluster** — Synchronous multi-master replication
- **Oracle Compatibility** — PL/SQL parser, packages, sequences
- **SkySQL** — Fully managed cloud database (AWS, Azure, GCP)
