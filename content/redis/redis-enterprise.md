**Category:** In-Memory Data Platforms | **Platform:** Redis Enterprise

## Overview

Redis Enterprise provides Active-Active geo-distribution (CRDTs), auto-tiering (Redis on Flash RAM+NVMe), sub-millisecond SLAs, and vector search capabilities for enterprise caching, real-time analytics, and GenAI/LLM architectures.

## Core Capabilities

- **Active-Active Geo-Distribution** — CRDT-based conflict-free replication across regions
- **Redis on Flash** — RAM+NVMe auto-tiering for cost-effective large datasets
- **Sub-Millisecond SLAs** — Guaranteed latency for real-time applications
- **Vector Search** — Native vector similarity search for GenAI/RAG workloads
- **Enterprise Security** — Encryption, RBAC, FIPS 140-2 compliance
