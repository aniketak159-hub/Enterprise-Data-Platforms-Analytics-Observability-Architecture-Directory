## 🔧 Core Capabilities

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin: 24px 0;">

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🔍 Elasticsearch
**Distributed search & analytics engine** — Full-text search, vector search, analytics aggregations, horizontal scaling with sharding and replication.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### ⚙️ Logstash
**Data processing pipelines** — Ingest, transform, enrich, and route data from diverse sources to Elasticsearch with 200+ plugins.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 📊 Kibana
**Visualization & dashboarding** — Interactive dashboards, Canvas, Lens, Maps, Machine Learning UI, and SIEM security workflows.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🛡️ Elastic SIEM
**Security analytics & threat detection** — Pre-built detection rules, MITRE ATT&CK mapping, timeline investigation, case management, compliance reporting.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 📝 Loki
**Cost-effective log aggregation** — Label-based indexing, multi-tenancy, Prometheus-native labels, Grafana-native querying with LogQL.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 📈 Mimir
**Long-term metrics storage** — Prometheus-compatible, horizontally scalable, native PromQL, ruler for alerting/recording rules, object storage backend.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 🔗 Tempo
**Distributed tracing backend** — TraceQL query language, high-volume trace ingestion, object storage, seamless Grafana integration for trace-to-metrics/logs correlation.

</div>

<div style="border: 1px solid #e1e4e8; border-radius: 8px; padding: 20px; background: #fafbfc;">

### 📊 Grafana Enterprise
**Unified visualization platform** — RBAC, audit logging, reporting, data source plugins, alerting with contact points, dashboard provisioning, teams & folders.

</div>
